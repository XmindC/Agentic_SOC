# Documentation

The folders are numbered in the order you would read them when building the lab from nothing.

| # | Folder | Read it when |
|---|---|---|
| 01 | [plan](01-plan/README.md) | You want the goal, the build order and what comes next |
| 02 | [architecture](02-architecture/README.md) | You need to know how an alert travels and why it was built that way |
| 03 | [lab](03-lab/README.md) | You need an address, an account or a port |
| 04 | [installation](04-installation/README.md) | You are building a machine |
| 05 | [configuration](05-configuration/README.md) | You are changing a rule, a decoder, the workflow or a service setting |
| 06 | [operations](06-operations/README.md) | The Mac restarted, you want to test the pipeline, or you are making a change |
| 07 | [troubleshooting](07-troubleshooting/README.md) | Something is silent or broken |
| 08 | [incident-reports](08-incident-reports/README.md) | You want an example of the reporting the lab produces |
| 09 | [agents](09-agents/README.md) | You are building or changing an AI agent |

Files under a `reference/` or `cases/` subfolder are the original session notes from the build, cleaned for publication. They are long and detailed, with every command that was run and why. The README in each folder is the short version.
